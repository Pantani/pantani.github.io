# Font assets

Latin subsets served locally preserve the existing design without a Google Fonts stylesheet request. Variable weight ranges: Fraunces 400–800, Inter 400–800, JetBrains Mono 400–600. Accented Portuguese characters are included in the Latin subset. Unsupported glyphs use CSS fallbacks.

Downloaded from Google Fonts on 2026-10-09; original SIL Open Font License files are retained with the assets.

Google Fonts CSS source: https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,400..800&family=Inter:wght@400..800&family=JetBrains+Mono:wght@400..600&display=swap
